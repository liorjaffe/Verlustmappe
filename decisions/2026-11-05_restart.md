# 2026-11-05 – Restart

## Why

The repository was sorted by process events (decisions, tasks, review rounds), not by
subject. Knowledge about one device was spread over up to 35 files, the current state sat
at the end of long logs. AI agents have no memory across sessions; they read the
repository, and there the old state won over what had only been settled in chat. Old
topics therefore kept coming back.

## Owner decisions of 2026-11-05

1. Restart on branch `neustart` in the same repository; `main` stays unchanged until the
   merge. Archive tag `archive-2026-11`.
2. The comparison with the legacy state (AC8) is dropped.
3. Layer 2 computes a given load profile, without sun-driven control.
4. Only devices with a direct influence on production. Ventilation, gas detection,
   heating, frost protection and room equipment are excluded.
5. There is no central plant control; device controls are contained in the consumption of
   the respective device.
6. Correction after N2: the device models (`devices/`, `hydrogen/`, `conversions.py`,
   `constants.py`) and their tests were restored. Removing them left the project unable to
   compute anything, which was the agent's error. Analyses, the old balance and loss map,
   Monte Carlo and the report generator stay in the archive until needed.
7. All repository content is in English.
8. CONTRACT §4–§6 proposals V1–V14 confirmed (A/B boundary, reporting rule for C,
   case rules, balance rules). The formula of C stays open.
9. Architecture approved and applied without losing computing code or data: packages
   physics/, hydrogen/, devices/ (named like plant/), accounting/, loaders/; identical
   duplicates merged only where proven identical; non-identical implementations kept
   side by side; tests named by package and topic; layout guarded by test_structure.
