## Acceptance

- Claude Code and Copilot instructions point to the root `AGENTS.md`.
- Protected paths have an owner in `.github/CODEOWNERS`.
- CI runs `python3 tests/run_all.py`, rejects removed/skipped tests, requires tests for
  registry edits, checks sources for newly added registry keys, and checks the generated
  README demo block.
- README demo bar values are generated by the existing synthetic full-chain test.
- GitHub branch protection is documented as a repository-admin action, not represented
  as configured by these files.
